# 不要久坐

一个本地 macOS 姿态和久坐强提醒小工具。

## 能做什么

- 默认使用随机 25-45 分钟观察窗口；也可以改成指定时长。
- 每个观察窗口内会平均采集不少于 10 张姿态样本，最少采样张数可在设置里调整。
- 摄像头只在每个采样点短暂打开，拿到画面后关闭，不在整个观察窗口内常开。
- 每拍到一张照片会先写入本地 `.in-progress` 临时目录，观察结束后移动到结束时间命名的文件夹。
- 摄像头刚启动时的纯黑预热帧会被忽略，不计入采样、不保存、不当作离席。
- 只要观察窗口结束时人在电脑前，就会弹窗并播放提醒；识别结果只影响提醒原因说明。
- 本地识别低头、含胸/驼背、身体左右歪斜。
- 如果姿势长时间没有明显变化，会提醒你调整。
- 如果观察窗口内检测到你离开座位，会取消本轮提醒；之后定期探测，等你回到电脑前再重新开始随机计时。
- 超过约 35 分钟未标记活动时，提醒久坐。
- 提醒方式可选：语音 + 弹窗、仅语音、仅弹窗。
- 触发方式可选：图片中观察到人像才触发、按时间触发。
- 有 Dock 图标和主窗口，可以查看当前状态、观察结束时间、下次拍照时间、暂停/恢复。
- 使用“准备起身活动的人”作为 App 和 DMG 图标。
- 保存本地提醒历史：时间、提醒原因、识别细节和一张代表性截图。
- 历史截图默认保留 7 天，可在窗口里改成 3/7/14/30/60/90 天。
- 提醒文案可以自定义，支持变量替换。
- 声音支持两种模式：朗读文案、播放自定义音频。
- 修改或恢复提醒文案后会自动清除自定义音频，并切回朗读文案。
- 文案输入框支持中文、复制粘贴、撤销、全选和恢复默认文案。
- 历史图片保留天数支持自定义输入，最小单位是天。
- 观察采样时间支持指定时间或随机范围；不调整时默认随机 25-45 分钟。
- 保存观察设置后会立即取消旧观察并按新设置重新开始。
- 每个观察窗口的采样照片会保存到以结束时间命名的文件夹中。

## 隐私边界

- 摄像头画面只在本机用于 Apple Vision 姿态观察。
- 只在提醒触发时保存一张本地截图，默认 7 天后滚动删除。
- 不上传网络。
- 不使用云端模型。

## 构建

```bash
./scripts/make-dmg.sh
```

生成结果：

```text
dist/不要久坐.dmg
```

## 使用

1. 打开 DMG，把 App 拖到任意位置或直接运行。
2. 首次运行时允许相机权限。
3. 程序坞会出现 App 图标，主窗口会显示当前状态和提醒历史。
4. 顶部菜单栏也会出现 `Posture`，可以手动开始观察、暂停/恢复或标记已活动。
5. 强提醒弹窗现在提供“开始活动 / 5 分钟后提醒 / 暂停 1 小时”，不再把你直接丢进“今天都不提醒”的状态。

## 时间设置

- `历史图片保留`：输入整数天，最小 1 天。
- `观察采样时间`：选择“指定时间”时输入一个分钟数；选择“随机时间”时输入最短和最长分钟数。
- `最少照片`：输入本轮观察至少要采集的照片张数，默认 10 张。
- App 会在这个观察窗口内平均拍够至少设置的照片张数，而不是等到时间结束后才开始拍。
- 状态区会显示秒级观察结束时间和下次拍照时间。
- 保存观察设置后立即生效；如果当前正在观察，会先停止旧采样并重新按新设置开始。
- 观察窗口结束且人在时一定会提醒活动；如果识别出低头、驼背、姿势不变或久坐，会在提醒原因里写清楚。
- 不修改时，默认随机观察窗口是 25-45 分钟。

## 提醒方式、声音和文案

主窗口里可以设置“提醒方式”：

- `触发方式`：
  - `观察到人像才触发`：默认模式。观察窗口内没人或离席时取消本轮提醒，等回到电脑前再重新开始。
  - `按时间触发`：观察窗口结束就提醒，不因为识别不到人像而取消。
- `语音 + 弹窗`：默认强提醒，同时播放声音并弹窗。
- `仅语音`：只播放朗读文案或自定义音频，不弹窗。
- `仅弹窗`：只弹出强提醒窗口，不播放声音。

主窗口里可以修改“提醒文案模板”。支持这些变量：

```text
{issues} = 识别到的问题
{minutes} = 本轮观察分钟数
{sampleCount} = 本轮采样张数
{motionScore} = 姿态变化幅度
{detail} = 观察详情
{reason} = 触发方式
```

默认文案已经使用全部变量。改乱后可以点“恢复默认文案”。

文案变成语音有两种机制：

- `朗读文案`：App 把模板变量替换成最终文字后，交给 macOS 本地 TTS 实时朗读。文案怎么改，语音就怎么读。
- `播放自定义音频`：播放你选择的固定音频文件，适合自己录一句提醒。这个模式不会根据文案重新生成新语音。

如果修改或恢复默认文案，App 会自动清除原来的自定义音频并切回 `朗读文案`，下一次提醒会用新文案实时朗读。

支持选择系统能播放的常见音频文件，例如 `mp3`、`m4a`、`wav`、`aiff`、`caf`。

## 历史记录

提醒触发后，主窗口会追加一条历史记录：

- 时间
- 提醒原因
- 触发方式
- 观察细节：窗口时长、采样张数、在位张数、姿态变化幅度、置信度
- 当次代表性截图
- 本轮观察采样文件夹名

保存目录：

```text
~/Library/Application Support/PostureBreakReminder
```

可以在主窗口中打开保存目录、修改保留天数或清空历史。
每个观察窗口的全部采样图最终保存在 `images/yyyy-MM-dd_HH-mm-ss/` 这类以结束时间命名的文件夹中；观察尚未结束时，临时文件会先出现在 `images/.in-progress/`。

## 识别说明

这是提醒级启发式识别，不是医学测量：

- 低头：主要看鼻子相对颈部/肩部的位置。
- 含胸/驼背：主要看颈部相对双肩的位置。
- 身体左右歪斜：主要看双肩高度差。
- 姿势长时间无变化：主要看观察窗口内鼻子、颈部和双肩关键点的变化幅度。
- 久坐：根据上次“标记为已活动”的时间估算。

笔记本摄像头是单目 2D，相机高度、坐姿、光线和画面裁切都会影响结果。后续可以根据你的真实使用情况继续校准阈值。
